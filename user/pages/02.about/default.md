![About Image](about.jpeg?cropResize=400,200){.left} This portal is a GravCMS-based sandbox used to test and demo Cloudflare features: CDN & caching, WAF, Bot Management, Rate Limiting, Transform Rules, Workers, Turnstile and more.

Each entry under **Use Cases** describes a scenario that can be reproduced against this site.
